# 截图与贴图（official.screenshot）

Windows 11 x64 官方独立插件，Go + Win32 / GDI，无 MyGo / WebView 依赖。1.1.0 需搭配支持 `activity` 与 `theme` 能力的宿主，分别用于保留贴图和同步软件主题。旧宿主不能同步自定义主题，也可能在空闲回收时结束贴图。

当前版本 1.6.1 缩小区域截图工具条的悬浮提示，并将提示居中定位到对应图标上方。沿用 1.6.0 的工具栏背景不透明度与渐变结束色修正；完整渐变同步需使用配套宿主，旧宿主仍可使用截图功能，但只显示主色。

## 使用

安装并启用后输入 `截图` / `screenshot` / `snap` / `截屏`。菜单包含区域截图、区域截图并原地贴图、当前显示器 / 全部显示器截图、全部显示器快速保存、保存目录、贴图显隐 / 关闭以及设置。

## 滚动长截图

像普通截图一样触发区域截图，选区确认前点击工具条上的「滚动截图」图标（L），直接沿用当前选区和冻结首帧开始拼接。搜索菜单和快捷键列表不再提供独立的长截图入口；旧版本直接命令仍保留兼容。

1. 拖选纵向滚动内容，建议避开不滚动的侧栏与滚动条；最小选区为 64×96 个物理像素。不再以操作系统的单一窗口边框作为选区合法性条件。
2. 点击「滚动截图」，直接沿用当前冻结首帧，旁边显示 280×420 DIP 的预览小窗。用户自行滚动页面，无需点击逐帧采集，插件不发送滚轮消息或移动鼠标。
3. 页面稳定后自动采样、检测重叠并拼接。预览只有图片与一圈细线，周围空白透明且可穿透鼠标；底部统一显示尺寸 / 帧数、暂停、取消和完成，完成始终在最右侧。鼠标悬停或 Tab 焦点显示操作说明，主要动作的焦点框保持可见。页面静止时保持等待，已有标注在匹配后合成。
4. 无法可靠匹配、滚动过快或高度重复的画面只更新小窗状态并保留已有结果；减小滚动幅度或回滚一些即可重试。预览优先位于选区外，重叠时由系统排除出捕获，不反复隐藏 / 显示。系统不支持排除且没有旁边空间时，保留选区并提示缩小选区。排除已有贴图时仅在整段采集期间隐藏一次，完成 / 取消时恢复。
5. 点「完成」后仍在原来的小窗检查结果，不扩成大窗口；用滚轮、滚动条、PgUp / PgDn、Home / End 查看，或复制、保存、贴图、继续采集。复制与保存使用完整分辨率；长图贴图先缩略到屏幕范围内，原始像素仍保留。

原选区始终显示紧贴物理像素边界的细线框，框内不填色、不拦截鼠标，也不抢焦点。采集时为强调色，暂停 / 完成后为中性边界，底部文字和按钮同时提示状态；继续采集恢复强调色，关闭后边框与预览一并销毁。边框只画在选区外侧并设置捕获排除，不污染输出。实时缩略图按显示器 DPI 取样，用平滑插值减少文字锯齿；复制 / 保存仍使用未缩放的完整像素。

拼接按重叠内容选择接缝并替换上一个画面的尾部，避免逐帧重复追加固定顶部 / 底部。图片、动态布局或高度重复内容可能无法可靠匹配，此时调整选区、减小滚动幅度或完成已有结果。手动采集要保留前后画面的重叠，避免直接翻过一整屏；已经滚过头时可以回滚一些再采集。

每段采集最多 2 分钟；累计最多 80 个成功帧、30,000 像素高度、3,200 万像素，先到任一上限即保留结果。完成后页面停留在用户滚动的位置。当前仅支持纵向屏幕像素拼接，不包含 DOM 整页导出、横向滚动或分页文档合并；受保护画面仍受系统限制。页面移动、关闭或其他窗口覆盖选区时，新画面可能不匹配，应恢复原内容后继续或完成已有结果。

## 区域截图与贴图

区域截图先冻结桌面。拖出区域后可拖动内部移动选区、拖动边缘调整大小。Enter 默认复制；直接贴图入口的 Enter 默认贴图；未选中标注工具时双击确认默认操作。工具条和 `Ctrl+C` / `Ctrl+S` / `P` 分别复制 / 另存为 / 贴图。未选中标注工具时 Esc / 右键取消，不改变剪贴板。输出失败保留选区以便重试；长截图启动失败恢复当前选区与标注。

主工具条为 398×34 DIP 的图标栏（按显示器 DPI 缩放）：矩形 R、椭圆 E、箭头 A、画笔 B、马赛克 M、文字 T、撤销、重做、滚动截图 L、贴图 P、保存、取消和完成。悬停显示名称与按键，提示使用 11 DIP 字号、按文字宽度收缩，居中显示在对应图标上方；靠近显示器边缘时限制在当前屏幕内，上方空间不足时显示在按钮下方。Tab / Shift+Tab 选择按钮，Enter 执行。选中绘图工具后展开颜色与粗细行；再次点击当前工具、Esc 或右键退出工具，以便调整选区。Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。绘图限制在选区内；中文文字通过原生输入框输入，Enter 确认，Esc 放弃本次文字。标注随复制、保存、贴图和长截图输出合成。

启用截图后，鼠标附近显示逐像素放大镜：17×11 网格、中心像素框、物理屏幕坐标、颜色样本与 RGB。靠近显示器边缘时换侧并限制在当前显示器范围内；拖选和调整边界时持续更新，使用最近邻放大，不对颜色做平滑插值。拖动时收起工具条，松开后显示，避免遮挡操作。

工具条、贴图菜单、设置菜单和放大镜共用宿主传入的背景、表面、文字、边框、强调色与圆角；深浅模式及自定义配色可以实时同步。字体大小保持系统工具界面字号，独立于搜索面板字号。新版宿主还传入背景不透明度与材质：右键菜单使用逐像素透明背景，文字和图标保持不透明；亚克力使用原生实时模糊与着色，云母使用系统背景材质，系统不支持时回退不透明底色，高对比度使用不透明表面。截图工具条基于同一冻结快照合成背景透明度与亚克力模糊，云母模式使用不透明主题底色，避免在冻结截图中透出实时变化的桌面。

1.6.0 的普通截图工具栏、长截图底部工具条和右键菜单共用主色 / 渐变结束色，按宿主同样的自上而下方向绘制。普通截图在冻结画面上合成；长截图工具条和菜单使用背景单独透明的图层，不淡化文字、图标或图片。未交互按钮不再铺一层不透明主色遮住渐变；强调色、悬停和禁用表面保留各自语义。主题变化实时更新，两端都按同一个不透明度处理，切换纯色会清除结束色。

贴图按截图的原位置和物理像素尺寸置顶显示，完全不透明，覆盖后方内容。首次出现不主动抢走原应用焦点。点击图片后：

- 方向键移动 1 个物理像素，Shift＋方向键移动 10 像素。
- 拖动移动；滚轮缩放；锁定位置后禁止移动和缩放。
- 右键菜单提供置顶、任务栏显示、阴影、锁定、重置、透明度、大小预设、90° / 180° 旋转、水平 / 垂直镜像、复制、另存为、作为文件打开、操作提示、隐藏和关闭。
- 键盘菜单键 / Shift+F10 打开主题菜单；上下选择，右方向键进入子菜单，左方向键返回，Enter 执行，Esc 收起。关闭菜单后仍可用方向键微调贴图。
- `Ctrl+C` 复制当前图片，`Ctrl+S` 另存为；Esc 关闭当前获得焦点的贴图。
- Ctrl 拖动将 PNG 文件拖到资源管理器或支持文件放置的应用；过早松开鼠标则取消。普通拖动仍移动贴图。
- 隐藏后输入 `截图 显示` 恢复；隐藏保留图片，关闭释放内存。

默认四周有柔和外阴影，右键关闭即可无阴影覆盖。再次截图默认包含当前可见的贴图、显示透明度与阴影，得到屏幕上的组合画面；捕获前关闭操作菜单。复制、保存和导出包含旋转 / 镜像后的像素，不包含显示缩放、透明度或阴影。重置恢复原位置、原尺寸、原方向与 100% 不透明度，并解除位置锁定。

在「设置 → 快捷键」启用插件命令，可直接区域截图、截图并贴图、当前屏幕截图或显示 / 隐藏全部贴图。推荐键 `Ctrl+Alt+A` / `Ctrl+Alt+P` 默认待启用，由宿主统一管理冲突。

## 配置与数据

`截图 设置` 打开两个可切换项：「再次截图时包含贴图」「新贴图显示阴影」，默认均开启。关闭包含贴图时，仅在捕获快照期间临时隐藏贴图，随后恢复。

配置自动保存到 `%LOCALAPPDATA%\FluentLauncher\plugin-data\official.screenshot\settings.json`，与可被升级替换的插件安装目录分离。用户选择的图片保存到指定文件；快速保存使用系统 Pictures 已知文件夹下的 `FluentLauncher` 目录，文件名含纳秒时间戳且禁止覆盖同名文件。

只在明确触发动作时捕获屏幕，不上传、不保留截图历史。贴图仅内存；退出 / 禁用 / 升级插件或宿主退出后消失。仅在主动选择「作为文件打开」或 Ctrl 拖动时，生成系统临时目录中的 PNG，以便外部程序访问；正常退出会尽力清理，强制结束、崩溃或外部应用占用时可能残留。另存为或快速保存的图片不清理。

窗口截图、延时、剪贴板图片贴图与 OCR 属于后续阶段，当前菜单不显示未实现入口。受保护内容、独占全屏、HDR 色彩不作兼容性承诺。
