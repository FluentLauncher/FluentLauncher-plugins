# 截图与贴图（official.screenshot）

Windows 11 x64 官方独立插件，Go + Win32 / GDI，无 MyGo / WebView 依赖。1.1.0 需搭配支持 `activity` 与 `theme` 能力的宿主，分别用于保留贴图和同步软件主题。旧宿主不能同步自定义主题，也可能在空闲回收时结束贴图。

当前版本 1.6.1 缩小区域截图工具条的悬浮提示，并将提示居中定位到对应图标上方。沿用 1.6.0 的工具栏背景不透明度与渐变结束色修正；完整渐变同步需使用配套宿主，旧宿主仍可使用截图功能，但只显示主色。

1.8.0 的录制支持 MP4（H.264，可带系统声音和麦克风）与 GIF，工具栏改为可拖动的单行布局，见下文「录制」。无需更新宿主。

1.9.0 增加窗口自动吸附，并把长截图的底部控制条改为与录制工具栏一致的单行图标条，见下文「区域截图与贴图」和「滚动长截图」。无需更新宿主。

## 使用

安装并启用后输入 `截图` / `screenshot` / `snap` / `截屏` / `录屏` / `record`。菜单包含区域截图、区域截图并原地贴图、当前显示器 / 全部显示器截图、全部显示器快速保存、区域 / 当前显示器录制、停止录制、截图与录制保存目录、贴图显隐 / 关闭以及设置。

## 录制（MP4 / GIF）

入口有三个：区域截图工具条上的「录制」图标（V）；搜索菜单或快捷键里的「区域录制」（推荐键 `Ctrl+Alt+R`，先拖选，Enter 直接进入录制）；「当前显示器录制」（不需要选区，录鼠标所在的显示器）。录制的是实时画面，选区时冻结的画面和已画的标注不带入录制。最小区域 32×32 个物理像素。

1. 选区旁出现一条 40 DIP 高的单行工具栏，优先放在选区下方，其次上方、右侧、左侧；选区占满显示器时放在显示器底部居中的位置。从左到右：拖动柄、计时、格式（MP4 / GIF）、帧率、画面缩放（100% / 75% / 50%）、录制、暂停、声音、标注工具（矩形、画笔、箭头、序号、撤销、清除）、移动选区、关闭。文字项点击即切换并即时保存，下次沿用。按住拖动柄或计时区域可以把工具栏拖到任意位置；开始前按住「移动选区」拖动，选区、线框和工具栏一起平移（尺寸不变）。悬停或 Tab 焦点在工具栏下方显示说明（靠近屏幕底边时显示在上方）；Tab 切换，Enter 执行，Esc 取消。
2. 声音按钮打开菜单，分别勾选「录制系统声音」「录制麦克风」，默认只开系统声音。两项都不选时图标变为静音，录出的 MP4 没有音轨。GIF 没有声音，此时按钮置灰。声音只能在开始前选择。
3. 点录制按钮后倒计时 3 秒（再点一次立即开始，或在设置里关闭倒计时）。开始录制时键盘焦点还给原来的应用，录制中点击或拖动工具栏不会抢走焦点。MP4 首次启动系统编码器约需 1 秒，计时从第一帧写入后开始走。
4. 录制中计时走动，缩放一格改为显示文件大小，录制按钮变为停止（保存），可暂停 / 继续、关闭（丢弃）。距离时长上限不足 10 秒时计时变为警示色。暂停期间的画面和声音都不进入结果。选区外侧有细线框：录制中为警示色，暂停为中性色。工具栏和线框都设置了捕获排除，不会出现在画面里；系统不支持排除时不显示悬停说明，工具栏不能拖进选区，且只能压在选区上时提示缩小选区，不开始录制。
5. 停止后文件保存为 `视频\FluentLauncher\Recording_日期_时间.mp4`（或 `.gif`）。工具栏变为结果条：时长与大小、复制文件（可粘贴到聊天或文件夹）、另存为、在文件夹中显示、打开、关闭。结果条留着不影响再次截图或录制；开始新的录制会替换它。

「停止录制」命令（推荐键 `Ctrl+Alt+Shift+R`）在录制中等同于停止并保存，在尚未开始（选项或倒计时阶段）时等同于取消。录制整块显示器时工具栏在画面内但不会被录进去，也可以直接用这个快捷键结束。

### 录制中标注

工具栏上的矩形、画笔、箭头、序号可以在开始前或录制中直接画在选区里，画出来的内容会被录进结果。选中工具后选区内的鼠标用于绘制（十字光标），被录制的应用暂时收不到鼠标，但键盘焦点不变；再点一次该工具或在选区内右键退出，鼠标恢复穿透，已画的标注保留。序号每点一次递增。「撤销」去掉最后一个标注，「清除」去掉全部。标注使用主题的警示色和固定粗细，停止、取消或关闭后消失，不影响下一次录制。移动选区时标注跟着移动。

标注层是盖在选区上的一个置顶透明窗口，没有标注也没有选中工具时不显示。选中工具期间它带有肉眼不可见的最低透明度（1/255）以接收鼠标。文字和马赛克暂未提供：文字需要键盘焦点，马赛克需要对实时画面逐帧处理。

### MP4

使用 Windows 自带的 Media Foundation 编码：H.264 视频，选择了声音时加一条 48 kHz 双声道 AAC 音轨，插件不携带编码器。帧率 15 / 30 / 60，默认 30；码率按画面大小和帧率估算，限制在 1–20 Mbps；优先使用硬件编码，硬件编码器不接受时自动改用软件编码。宽高必须是偶数：奇数边在 100% 缩放时裁掉 1 个像素（不重采样整幅画面），缩放后的尺寸向下取偶；超过 4096×2304 时等比缩小。单段默认最长 60 分钟（配置文件可改，5 秒到 4 小时）。

系统声音采集的是默认播放设备正在播放的内容（WASAPI loopback），麦克风采集默认录音设备；两路由系统转换为同一格式后按各自音量混合。系统没有声音时采集不会送数据，这段时间补静音，画面和声音保持对齐；声音相对画面有约 50 毫秒的固定缓冲。没有对应设备，或系统隐私设置不允许桌面应用访问麦克风时，录制不会开始并提示原因，在声音菜单里关闭那一路即可继续。录制中设备被拔出或切换时，这一路之后为静音，录制继续。精简版 Windows（N 版）没有安装媒体功能包时无法录制 MP4，会提示改用 GIF。

### GIF

帧率 10 / 15 / 20，默认 15；单段默认最长 60 秒（配置文件可改，5–600 秒）。使用固定 252 色调色板和位置固定的有序抖动：文字和纯色界面清晰，照片、渐变和视频会有颗粒感。每帧只写入与上一帧不同的矩形，其中没变的像素设为透明；画面不动时只延长上一帧的显示时间，所以静止画面几乎不占体积，内存占用也不随时长增加。

### 共同行为

编码跟不上设定帧率时自动少录几帧，不会卡住或堆积内存。录制过程中文件名带 `.partial` 后缀，完成后才改为正式名称；取消会删除它。插件或宿主正常退出时会先把正在进行的录制收尾保存（最多等 3 秒）；进程被强制结束时只会留下 `.partial` 文件，未收尾的 MP4 无法播放。锁屏、UAC 安全桌面期间无法读取画面，这段时间保留上一帧，回到桌面后继续。鼠标指针默认录入，可在设置里关闭。已有贴图是屏幕内容的一部分，会被录进去。受保护内容、独占全屏与 HDR 色彩同截图一样不作承诺。

## 滚动长截图

像普通截图一样触发区域截图，选区确认前点击工具条上的「滚动截图」图标（L），直接沿用当前选区和冻结首帧开始拼接。搜索菜单和快捷键列表不再提供独立的长截图入口；旧版本直接命令仍保留兼容。

1. 拖选纵向滚动内容，建议避开不滚动的侧栏与滚动条；最小选区为 64×96 个物理像素。不再以操作系统的单一窗口边框作为选区合法性条件。
2. 点击「滚动截图」，直接沿用当前冻结首帧，旁边显示 280×420 DIP 的预览小窗。用户自行滚动页面，无需点击逐帧采集，插件不发送滚轮消息或移动鼠标。
3. 页面稳定后自动采样、检测重叠并拼接。预览只有图片与一圈细线，周围空白透明且可穿透鼠标；底部是一条 40 DIP 高的单行控制条：左侧显示尺寸 / 帧数，右侧依次是暂停、取消和完成三个图标按钮，完成使用强调色并始终在最右侧。鼠标悬停或 Tab 焦点时左侧文字换成该按钮的说明，主要动作的焦点框保持可见。页面静止时保持等待，已有标注在匹配后合成。
4. 无法可靠匹配、滚动过快或高度重复的画面只更新小窗状态并保留已有结果；减小滚动幅度或回滚一些即可重试。预览优先位于选区外，重叠时由系统排除出捕获，不反复隐藏 / 显示。系统不支持排除且没有旁边空间时，保留选区并提示缩小选区。排除已有贴图时仅在整段采集期间隐藏一次，完成 / 取消时恢复。
5. 点「完成」后仍在原来的小窗检查结果，不扩成大窗口；用滚轮、滚动条、PgUp / PgDn、Home / End 查看；控制条左侧显示长图的完整尺寸，右侧为复制（强调色）、保存、贴图、继续采集，以及用分隔线隔开的关闭。输出过程中按钮只变为灰色图标，不再铺灰底。复制与保存使用完整分辨率；长图贴图先缩略到屏幕范围内，原始像素仍保留。

原选区始终显示紧贴物理像素边界的细线框，框内不填色、不拦截鼠标，也不抢焦点。采集时为强调色，暂停 / 完成后为中性边界，底部文字和按钮同时提示状态；继续采集恢复强调色，关闭后边框与预览一并销毁。边框只画在选区外侧并设置捕获排除，不污染输出。实时缩略图按显示器 DPI 取样，用平滑插值减少文字锯齿；复制 / 保存仍使用未缩放的完整像素。

拼接按重叠内容选择接缝并替换上一个画面的尾部，避免逐帧重复追加固定顶部 / 底部。图片、动态布局或高度重复内容可能无法可靠匹配，此时调整选区、减小滚动幅度或完成已有结果。手动采集要保留前后画面的重叠，避免直接翻过一整屏；已经滚过头时可以回滚一些再采集。

每段采集最多 2 分钟；累计最多 80 个成功帧、30,000 像素高度、3,200 万像素，先到任一上限即保留结果。完成后页面停留在用户滚动的位置。当前仅支持纵向屏幕像素拼接，不包含 DOM 整页导出、横向滚动或分页文档合并；受保护画面仍受系统限制。页面移动、关闭或其他窗口覆盖选区时，新画面可能不匹配，应恢复原内容后继续或完成已有结果。

## 区域截图与贴图

区域截图先冻结桌面，同时记录此刻各窗口的位置。还没有选区时，鼠标所在的窗口以原亮度显示并画强调色边框，左上角提示条显示它的尺寸：单击即选中这个窗口，按下后拖动超过 4 个物理像素则仍是手动拖选；双击相当于选中并执行默认操作。已有选区时在选区外单击，会改选单击处的窗口。吸附按窗口的前后顺序取最上面的一个，并细化到鼠标下最里层的子窗口（至少 24 像素见方）；边界使用不含隐形缩放边的可见边框，最大化窗口裁到所在显示器；鼠标在桌面上时吸附到当前显示器；本插件的贴图也可以吸附。其他虚拟桌面的窗口、最小化窗口和鼠标穿透的浮层不参与。浏览器、Electron 等自绘程序内部没有子窗口，只能吸附到整个窗口或页面内容区，不能吸附到网页里的元素。可在设置里关闭。

拖出区域后可拖动内部移动选区、拖动边缘调整大小。Enter 默认复制；直接贴图入口的 Enter 默认贴图；未选中标注工具时双击确认默认操作。工具条和 `Ctrl+C` / `Ctrl+S` / `P` 分别复制 / 另存为 / 贴图。未选中标注工具时 Esc / 右键取消，不改变剪贴板。输出失败保留选区以便重试；长截图启动失败恢复当前选区与标注。

主工具条为 428×34 DIP 的图标栏（按显示器 DPI 缩放）：矩形 R、椭圆 E、箭头 A、画笔 B、马赛克 M、文字 T、撤销、重做、滚动截图 L、录制 V、贴图 P、保存、取消和完成。悬停显示名称与按键，提示使用 11 DIP 字号、按文字宽度收缩，居中显示在对应图标上方；靠近显示器边缘时限制在当前屏幕内，上方空间不足时显示在按钮下方。Tab / Shift+Tab 选择按钮，Enter 执行。选中绘图工具后展开颜色与粗细行；再次点击当前工具、Esc 或右键退出工具，以便调整选区。Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。绘图限制在选区内；中文文字通过原生输入框输入，Enter 确认，Esc 放弃本次文字。标注随复制、保存、贴图和长截图输出合成。

启用截图后，鼠标附近显示逐像素放大镜：17×11 网格、中心像素框、物理屏幕坐标、颜色样本与 RGB。靠近显示器边缘时换侧并限制在当前显示器范围内；拖选和调整边界时持续更新，使用最近邻放大，不对颜色做平滑插值。拖动时收起工具条，松开后显示，避免遮挡操作。

工具条、贴图菜单、设置菜单和放大镜共用宿主传入的背景、表面、文字、边框、强调色与圆角；深浅模式及自定义配色可以实时同步。字体大小保持系统工具界面字号，独立于搜索面板字号。新版宿主还传入背景不透明度与材质：右键菜单使用逐像素透明背景，文字和图标保持不透明；亚克力使用原生实时模糊与着色，云母使用系统背景材质，系统不支持时回退不透明底色，高对比度使用不透明表面。截图工具条基于同一冻结快照合成背景透明度与亚克力模糊，云母模式使用不透明主题底色，避免在冻结截图中透出实时变化的桌面。

1.6.0 的普通截图工具栏、长截图底部工具条和右键菜单共用主色 / 渐变结束色，按宿主同样的自上而下方向绘制。普通截图在冻结画面上合成；长截图工具条和菜单使用背景单独透明的图层，不淡化文字、图标或图片。未交互按钮不再铺一层不透明主色遮住渐变；强调色、悬停和禁用表面保留各自语义。主题变化实时更新，两端都按同一个不透明度处理，切换纯色会清除结束色。

贴图按截图的原位置和物理像素尺寸置顶显示，完全不透明，覆盖后方内容。首次出现不主动抢走原应用焦点。点击图片后：

- 方向键移动 1 个物理像素，Shift＋方向键移动 10 像素。
- 拖动移动；滚轮缩放；锁定位置后禁止移动和缩放。
- 右键菜单提供置顶、任务栏显示、阴影、锁定、重置、透明度、大小预设、90° / 180° 旋转、水平 / 垂直镜像、复制、另存为、作为文件打开、操作提示、隐藏和关闭。
- 键盘菜单键 / Shift+F10 打开主题菜单；上下选择，右方向键进入子菜单，左方向键返回，Enter 执行，Esc 收起。关闭菜单后仍可用方向键微调贴图。
- `Ctrl+C` 复制当前图片，`Ctrl+S` 另存为；Esc 关闭当前获得焦点的贴图。
- Ctrl 拖动将 PNG 文件拖到资源管理器或支持文件放置的应用；过早松开鼠标则取消。普通拖动仍移动贴图。
- 隐藏后输入 `截图 显示` 恢复；隐藏保留图片，关闭释放内存。

默认四周有柔和外阴影，右键关闭即可无阴影覆盖。再次截图默认包含当前可见的贴图、显示透明度与阴影，得到屏幕上的组合画面；捕获前关闭操作菜单。复制、保存和导出包含旋转 / 镜像后的像素，不包含显示缩放、透明度或阴影。重置恢复原位置、原尺寸、原方向与 100% 不透明度，并解除位置锁定。

在「设置 → 快捷键」启用插件命令，可直接区域截图、截图并贴图、当前屏幕截图或显示 / 隐藏全部贴图。推荐键 `Ctrl+Alt+A` / `Ctrl+Alt+P` 默认待启用，由宿主统一管理冲突。

## 配置与数据

`截图 设置` 打开五个可切换项：「再次截图时包含贴图」「新贴图显示阴影」「录制时包含鼠标指针」「录制前倒计时 3 秒」「截图时自动吸附窗口」（配置项 `snapWindows`），默认均开启。关闭包含贴图时，仅在捕获快照期间临时隐藏贴图，随后恢复。

录制选项保存在同一文件的 `recording` 下：`format`（`mp4` / `gif`，默认 `mp4`）、`mp4Fps`（15 / 30 / 60，默认 30）、`gifFps`（10 / 15 / 20，默认 15）、`scale`（100 / 75 / 50，默认 100）、`mp4MaxSeconds`（5–14400，默认 3600）、`gifMaxSeconds`（5–600，默认 60）、`systemAudio`（默认开）、`microphone`（默认关）、`systemVolume` 与 `micVolume`（0–100，默认 100，只能在配置文件里改）、`cursor`、`countdown`。旧配置文件没有这一段或缺少某项时使用默认值；不支持的取值在读取时回到默认值。录制结果保存在系统 Videos 已知文件夹下的 `FluentLauncher` 目录，文件名含纳秒时间戳。

只在明确触发动作时捕获屏幕，不上传、不保留截图历史。录制只在点击开始后读取画面，结果只写入上述视频目录或你另存的位置。贴图仅内存；退出 / 禁用 / 升级插件或宿主退出后消失。仅在主动选择「作为文件打开」或 Ctrl 拖动时，生成系统临时目录中的 PNG，以便外部程序访问；正常退出会尽力清理，强制结束、崩溃或外部应用占用时可能残留。另存为或快速保存的图片不清理。
