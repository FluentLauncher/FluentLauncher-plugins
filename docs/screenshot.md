# 截图与贴图（official.screenshot）

Windows 11 x64 官方独立插件，Go + Win32 / GDI，无 MyGo / WebView 依赖。必须搭配支持 `activity` 能力的宿主，旧宿主可能在空闲回收时结束贴图。

## 使用

安装并启用后输入 `截图` / `screenshot` / `snap` / `截屏`。菜单包含区域截图、区域截图并原地贴图、当前显示器 / 全部显示器截图、全部显示器快速保存、保存目录、贴图显隐 / 关闭以及设置。

区域截图先冻结桌面。拖出区域后可拖动内部移动选区、拖动边缘调整大小。Enter 默认复制；直接贴图入口的 Enter 默认贴图；双击确认默认操作。工具条和 `Ctrl+C` / `Ctrl+S` / `P` 分别复制 / 另存为 / 贴图。Esc / 右键取消，不改变剪贴板。输出失败保留选区以便重试。

贴图按截图的原位置和物理像素尺寸置顶显示，完全不透明，覆盖后方内容。首次出现不主动抢走原应用焦点。点击图片后：

- 方向键移动 1 个物理像素，Shift＋方向键移动 10 像素。
- 拖动移动；滚轮缩放；锁定位置后禁止移动和缩放。
- 右键操作复制原图、另存为、阴影、锁定、恢复原始大小、回到原始位置、隐藏、关闭；键盘菜单键 / Shift+F10 也可打开原生菜单。
- `Ctrl+C` 复制原图，`Ctrl+S` 另存为；Esc 关闭当前获得焦点的贴图。
- 隐藏后输入 `截图 显示` 恢复；隐藏保留图片，关闭释放内存。

默认四周有柔和外阴影，右键关闭即可无阴影覆盖。再次截图默认包含当前可见的贴图与阴影，得到屏幕上的组合画面；复制和保存某张贴图始终输出原图，不包含阴影或缩放。

在「设置 → 快捷键」启用插件命令，可直接区域截图、截图并贴图、当前屏幕截图或显示 / 隐藏全部贴图。推荐键 `Ctrl+Alt+A` / `Ctrl+Alt+P` 默认待启用，由宿主统一管理冲突。

## 配置与数据

`截图 设置` 打开两个可切换项：「再次截图时包含贴图」「新贴图显示阴影」，默认均开启。关闭包含贴图时，仅在捕获快照期间临时隐藏贴图，随后恢复。

配置自动保存到 `%LOCALAPPDATA%\FluentLauncher\plugin-data\official.screenshot\settings.json`，与可被升级替换的插件安装目录分离。用户选择的图片保存到指定文件；快速保存使用系统 Pictures 已知文件夹下的 `FluentLauncher` 目录，文件名含纳秒时间戳且禁止覆盖同名文件。

只在明确触发动作时捕获屏幕，不上传、不保留截图历史、不自动写额外图片。贴图仅内存；退出 / 禁用 / 升级插件或宿主退出后消失。

窗口截图、延时、剪贴板图片贴图、滚动长截图、标注与 OCR 属于后续阶段，当前菜单不显示未实现入口。受保护内容、独占全屏、HDR 色彩不作兼容性承诺。

## 验证

常规 `go test ./...` 覆盖路由、状态保活、物理像素微调、锁定、DIB 方向与颜色、PNG 往返、配置保存与 manifest。SDK 模块另行构建 / 检查 / 测试。宿主覆盖 activity 协议与空闲回收。

原生检查需显式开启，会短暂显示测试生成的图片与选区窗口，不发送桌面鼠标 / 键盘输入、不写用户剪贴板。仅保存合成测试图片：

```powershell
$env:FL_SCREENSHOT_NATIVE_TEST = '1'
$env:FL_SCREENSHOT_ARTIFACT_DIR = "$PWD/build/screenshot-native"
go test ./plugins/screenshot -run '^TestNativePinCompositeAndKeyboard$' -count=1 -v
```

原生检查覆盖位图像素、真实桌面二次捕获保留贴图、阴影开关、WM_KEYDOWN 微调和锁定、恢复位置、隐藏 / 恢复、选区生成贴图、全部关闭后的 activity。产物应视觉检查。实际快捷键端到端、保存对话框、剪贴板目标应用、多显示器混合 DPI、长时间存活需按设备条件实机验收，不能由无头测试替代。
